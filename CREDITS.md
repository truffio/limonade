# Credits

## Sounds

Every sound in the game (sound effects, rain and the background music) is synthesized in code with the Web Audio API, in `src/audio/`. The game ships no audio files, so there are no third-party sound licenses to track.

If recorded sounds are added later, list each file here with its source and license (CC0 or another license that allows redistribution).
